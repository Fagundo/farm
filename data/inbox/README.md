# Redfin exports go here

1. On redfin.com, search an area (e.g. a county), set filters: For sale, price up to $1M, lot size 5–80 acres.
2. Switch to the list/table view, scroll to the bottom, click **Download All** (needs 20+ results; max 350).
3. Put the CSV in this folder (on GitHub: **Add file → Upload files**). The next run scores it;
   pushing a file here also starts a run.

Homes already in the database are skipped, so old files can stay.
